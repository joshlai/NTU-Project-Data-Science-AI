# Instructions on how execute the set up file.
This section here  automates the installation of conda and git in the vm. It also uses an environment 


## Step 1

Upload setup.sh to the vm home folder via the web browser terminal
To make your script executable, follow these steps:

The File to upload is  setup.sh

## Step 2
Run this command to make it executable:

chmod +x setup.sh


## Step 3
Execute the script:


./setup.sh
